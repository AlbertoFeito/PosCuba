# Atajos de teclado

El programa está pensado para usarse con el teclado y el lector de barras. Los atajos también aparecen en los botones y al pie de cada pantalla.

## En todo el programa

| Tecla | Acción |
|---|---|
| F1 | Manual en la sección de lo que tienes delante |
| Ctrl+1 | Venta |
| Ctrl+2 | Productos |
| Ctrl+3 | Inventario |
| Ctrl+4 | Caja |
| Ctrl+5 | Reportes |
| Ctrl+6 | Configuración |
| Ctrl+7 | Usuarios |
| Ctrl+8 | Respaldos |
| Ctrl+9 | Estado |
| Ctrl+L | Cerrar sesión |
| Ctrl+Q | Salir del programa |

## Venta

| Tecla | Acción |
|---|---|
| F2 | Ir al buscador |
| Enter | Agregar el código o nombre escrito |
| `3*código` | Agregar 3 unidades |
| ↓ / ↑ | Moverse por los resultados o por el carrito |
| Ctrl+↑ / Ctrl+↓ | Elegir línea del carrito |
| + / − | Sumar o restar 1 a la línea elegida (buscador vacío) |
| F3 | Cambiar la cantidad |
| Supr | Quitar la línea elegida (buscador vacío) |
| F7 | Descuento (Tab cambia importe / %) |
| F4 | Cobrar |
| F10 | Ventas recientes y reimprimir |
| F8 | Abrir caja |
| Esc | Limpiar el buscador; con el buscador vacío, cancelar la venta |

## Cobro

| Tecla | Acción |
|---|---|
| Enter o Ctrl+S | Confirmar la venta |
| F6 | Cambiar la moneda del efectivo |
| Tab | Siguiente campo |
| Esc | Volver al carrito |

## Productos

| Tecla | Acción |
|---|---|
| Ctrl+N | Nuevo producto |
| F2 | Buscar |
| Enter o F3 | Editar el elegido |
| Supr | Desactivar o reactivar |
| Ctrl+S | Guardar (en la ventana del producto) |

## Inventario

| Tecla | Acción |
|---|---|
| F2 | Buscar |
| F5 o Enter | Entrada de mercancía |
| F6 | Ajuste de stock |

## Caja

| Tecla | Acción |
|---|---|
| F8 | Abrir caja |
| F9 | Cerrar caja (arqueo) |

## Otras pantallas

| Tecla | Acción |
|---|---|
| Ctrl+N (Usuarios) | Nuevo usuario |
| Supr (Usuarios) | Desactivar o reactivar |
| Ctrl+B (Respaldos) | Respaldar ahora |
| Ctrl+S (Configuración) | Guardar |

## Entrada (PIN)

| Tecla | Acción |
|---|---|
| ← / → | Cambiar de usuario |
| Enter | Entrar |

## En este manual

| Tecla | Acción |
|---|---|
| Ctrl+F | Buscar |
| ↑ / ↓ y Enter | Elegir y abrir una sección |
| Re Pág / Av Pág | Desplazar el texto |
| Alt+← | Volver a la sección anterior |
| Esc | Cerrar |

## En las ventanas

En casi todas las ventanas, **Enter** confirma y **Esc** cancela. El botón principal (en azul) es el que ejecuta Enter.
